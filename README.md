# Medical Member Interactive Dashboard (ฐานข้อมูลสมาชิก ราชวิทยาลัยและสมาคม)

ระบบ **Interactive Dashboard** อัจฉริยะสำหรับสืบค้น วิเคราะห์ แสดงผลพิกัดภูมิศาสตร์ และจัดการแก้ไขฐานข้อมูลสมาชิกแพทย์เวชศาสตร์ครอบครัว โดยประมวลผลข้อมูลครอบคลุมทั้ง 5 Tabs จาก [Google Spreadsheet Master DB (18sXvaCY...)](https://docs.google.com/spreadsheets/d/1PVM2qdbidgsFVCZhgLW160PD3rcN39Vrac75OH-tYFU/edit?usp=drive_link) ในโฟลเดอร์ Google Drive [ระบบสมาชิก](https://drive.google.com/drive/folders/1kG-hz2vQ1hwbw-vX2xs80PyZhAN9ARz6?usp=sharing)

## 🌟 ฟังก์ชันหลักของระบบ (Key Features)

### 1. 📊 ภาพรวมสถิติและเป้าหมาย (Executive Dashboard)
- **KPI Cards**: สมาชิกที่อัปเดตข้อมูลแล้ว (314 ราย), สัดส่วนวุฒิบัตร วว. (Formal vs Inservice), หนังสืออนุมัติ (อว.), และอัตราการปักหมุดพิกัด
- **Target Progress Tracking**: ติดตามความก้าวหน้าเทียบกับเป้าหมายใน Tab `Dashboard` (วว. 1,626 คน และ อว. 6,357 คน)
- **Interactive Charts (Chart.js)**:
  - สัดส่วนประเภทคุณวุฒิ (Formal 108 คน / Inservice 148 คน / อว. 58 คน)
  - 10 อันดับสถาบันการศึกษาแพทยศาสตร์
  - 10 จังหวัดที่มีแพทย์ปฏิบัติงานมากที่สุด
  - สัดส่วนสถานที่ทำงาน (รัฐบาล 90%+ vs เอกชน vs ส่วนตัว)

### 2. 🗺️ แผนที่พิกัดแพทย์ทั่วประเทศ (Interactive Map)
- ขับเคลื่อนด้วย **Leaflet.js** + **MarkerCluster**
- ปักหมุดพิกัดแพทย์กว่า 312 จุดทั่วประเทศ พร้อมแยกสีหมุดตามประเภทคุณวุฒิ:
  - 🔵 **สีน้ำเงิน**: วว. แผน ก (Formal training)
  - 🟢 **สีเขียว**: วว. แผน ข (Inservice training)
  - 🟡 **สีเหลือง/ส้ม**: หนังสืออนุมัติ (อว.)
- **Popup Card สวยงาม**: คลิกที่หมุดเพื่อดูรูปถ่ายแพทย์, ชื่อ-สกุล, โรงพยาบาล, เลข ว., เบอร์โทร และปุ่มเปิดดูประวัติฉบับเต็ม / ปุ่มแก้ไข
- **แถบตัวกรองบนแผนที่**: กรองตามประเภทคุณวุฒิ, กรองตามจังหวัด, กรองตามสังกัด (รัฐ/เอกชน), และสลับการรวมกลุ่ม (Cluster Toggle)

### 3. 👥 ทำเนียบสมาชิกและรูปถ่าย (Member Directory)
- สลับมุมมองได้ทั้งแบบ **การ์ด (Card Grid)** และ **ตารางข้อมูล (Data Table)**
- ค้นหาแบบเรียลไทม์ (ชื่อ, นามสกุล, เลข ว., โรงพยาบาล, จังหวัด, เบอร์โทร, อีเมล)
- ตัวกรองละเอียด (คุณวุฒิ, จังหวัด, สังกัด, มีรูป/ยังไม่มีรูป)
- จัดเรียงข้อมูล (ชื่อ ก-ฮ, เลข ว., จังหวัด)
- ระบบแบ่งหน้า (Pagination) 12 รายการต่อหน้า
- **Profile Modal**: คลิกดูข้อมูลประวัติละเอียดทั้ง 60 ฟิลด์ พร้อมแผนที่ Mini Map ตำแหน่งที่ทำงาน และปุ่มพิมพ์ประวัติ (Print)

### 4. ✏️ ระบบแก้ไขและจัดการข้อมูล (Data Editing & Management)
- **แก้ไขข้อมูลสมาชิก (Edit Member)**: ปรับปรุงข้อมูลส่วนตัว, คุณวุฒิ, โรงพยาบาล, ที่อยู่, เบอร์โทร, อีเมล และลิงก์รูปภาพ
- **Auto-Geocoding จาก Tab Geo**: เมื่อกรอกหรือเปลี่ยน ตำบล/อำเภอ/จังหวัด ในฟอร์มแก้ไข ระบบจะค้นหาพิกัด Lat/Lng จาก Tab `Geo` และเติมให้อัตโนมัติทันที
- **เพิ่มสมาชิกใหม่ (Add New Member)**: มีฟอร์มเพิ่มข้อมูลสมาชิกใหม่พร้อมบันทึกเข้าสู่ระบบ
- **ลบสมาชิก (Delete Member)**: มีระบบยืนยันความปลอดภัยก่อนลบ
- **บันทึกถาวร (LocalStorage Persistence)**: บันทึกการแก้ไข/เพิ่ม/ลบ ลงในเบราว์เซอร์อัตโนมัติ ข้อมูลไม่หายเมื่อรีเฟรชหน้าเว็บ
- **ส่งออกข้อมูล (Export CSV & JSON)**: ส่งออกเป็น CSV แบบ 60 คอลัมน์ที่สามารถ Import กลับเข้า Google Sheets ได้ทันที
- **รีเซ็ตข้อมูลสู่ต้นฉบับ**: สามารถกดปุ่ม Reset เพื่อย้อนกลับสู่ข้อมูลเดิมจาก Google Sheet ได้ตลอดเวลา

### 5. 🖼️ คลังรูปภาพ (Photo Gallery)
- รวมภาพถ่ายสมาชิกแพทย์ ดึงตรงจาก Google Drive Thumbnail CDN ความเร็วสูง
- ตัวกรอง: แสดงเฉพาะที่มีรูป / แสดงเฉพาะที่ยังไม่มีรูป เพื่อการติดตามข้อมูลที่สะดวกรวดเร็ว

### 6. 📍 ฐานข้อมูลพิกัด (Geo Master Data)
- แสดงข้อมูลพิกัดตำบล/อำเภอ/จังหวัด จาก Tab `Geo` (867 รายการ)
- ค้นหาและดูหมุดบนแผนที่ได้ทันที

## 🚀 วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: เปิดใช้งานผ่าน Python Server (แนะนำ)
เปิด Terminal และรันคำสั่ง:
```bash
python3 /Users/macbookair/.gemini/antigravity/scratch/medical-member-dashboard/serve.py
```
เบราว์เซอร์จะเปิดไปที่ `http://localhost:8080` โดยอัตโนมัติ

### วิธีที่ 2: ดับเบิลคลิกเปิดไฟล์โดยตรง (Zero Dependencies)
เปิด Finder ไปที่โฟลเดอร์:
`/Users/macbookair/.gemini/antigravity/scratch/medical-member-dashboard/`
แล้วดับเบิลคลิกที่ไฟล์ `index.html` เพื่อเปิดใช้งานบน Google Chrome, Safari หรือ Edge ได้ทันที
